# Inferbus Compose Infrastructure

Run `docker compose -f deploy/docker-compose.yaml up -d --build` to boot the complete stack. The gateway serves the OpenAI-compatible API on port 8080 in control-plane (`iam.mode: kv`) mode, configured by `gateway.kv.example.yaml` — create a key through the control plane's admin API before calling it, and swap in `gateway.example.yaml` if you want the static checked-in key `ib_dev_change_me` instead. The worker processes inference requests and exposes no HTTP surface at all — no `/metrics`, no health endpoints. The control plane (port 8081, event-sourced on es-lite, Postgres-backed — see `controlplane.example.yaml`) and the harvester (ClickHouse-backed usage/budget pipeline — see `harvester.example.yaml`) both start automatically alongside them; Postgres and ClickHouse back those two services rather than sitting idle. See the root [README.md](../README.md) for the control plane and budgets quickstarts.

## Metrics

The gateway and the harvester each expose Prometheus metrics on their own port — `GET http://localhost:8080/metrics` and `GET http://localhost:8082/metrics` respectively. The worker and the control plane expose no `/metrics`. A starter Grafana dashboard for the ClickHouse-backed usage data (not these Prometheus metrics) lives at [`grafana-usage.json`](grafana-usage.json) — import it into Grafana and point its `DS_CLICKHOUSE` template variable at a ClickHouse datasource backed by the compose stack's `usage_events` table.
