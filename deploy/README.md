# Inferbus Compose Infrastructure

Run `docker compose -f deploy/docker-compose.yaml up -d --build` to boot the complete stack. The gateway serves the OpenAI-compatible API on port 8080 with bearer token auth (configure via `gateway.example.yaml`, example key `ib_dev_change_me`). The worker processes inference requests. The control plane (port 8081, event-sourced on es-lite, Postgres-backed — see `controlplane.example.yaml`) and the harvester (ClickHouse-backed usage/budget pipeline — see `harvester.example.yaml`) both start automatically alongside them; Postgres and ClickHouse back those two services rather than sitting idle. See the root [README.md](../README.md) for the control plane and budgets quickstarts.
